### Paste a GitHub or GitLab link into Search

Search now accepts a repository link — `github.com/owner/repo`, a GitLab link, or just `owner/repo` — and looks that repository up directly, even if it is not in the app's list and even if the source is switched off. GitHub cannot be searched by Android package name at all, so naming the repository is the reliable way to find an app that lives only there.

If the repository is not followed yet, a **Track updates** button adds it to Custom Repositories, and update checks include it from then on.

### Search tells you when a source did not answer

Search used to say "Nothing found" even when a source had failed, most often GitHub after its hourly request limit was used up (easy to hit behind a VPN, where many people share one address). Now it names the sources that did not answer, both on an empty result and above a partial one.

### This fork in the app list

Searching for "apkupdater" now finds this app, not the original author's CI builds.

### Android TV

- **Calmer focus.** Settings rows, the top-bar buttons, the chips and the Check button no longer turn into a white block when focused. They get a slightly lighter background with a thin frame instead. The update cards keep their glow.
- **Rows no longer slide under the top bar.** Focusing a card's buttons used to scroll the card up until its top was hidden, most visibly right after a check. The whole row now stays in view.
- Source filter chips show whether they are selected even while focused.
